# 律所 H5 公众号平台方案

## 1. 项目定位
- 面向公众的移动端（微信公众号 H5）法律服务入口，提供咨询、法律文书、律师预约等业务。
- 风格参考政务/医院预约系统，强调信任、安全、权威。
- 目标：在线连接律所与用户、标准化服务流程、打造高端品牌形象。

## 2. 功能大纲
1. **首页/导航**：品牌展示、公告、快捷服务入口。
2. **律师列表与详情**：多维筛选、律师档案、预约档期。
3. **服务下单流程**：咨询/文书/诉讼等标准化下单、资料上传、支付。
4. **在线咨询/即时沟通**：会话列表、消息收发、语音留言（依第三方 IM）。
5. **法律文书定制**：模板选择、问答式信息收集、文书交付确认。
6. **订单与进度中心**：统一查看咨询、文书、预约订单及状态。
7. **消息中心**：系统通知、律师回复、支付提醒。
8. **用户中心**：实名、资料、合同/文书下载、发票申请。
9. **（可选）后台管理**：律师、订单、内容管理与数据看板。

## 4. 技术架构与要点
- **前端**：Vue3 + Vite + TypeScript，Ant Design Mobile（政务风主题），公众号内嵌浏览器优化。
- **后端**：NestJS（Node.js）/Spring Boot，可插拔服务模块；提供律师、订单、支付、消息接口。
- **数据层**：MySQL（业务数据）+ Redis（会话、缓存）+ 对象存储（合同、文书附件）。
- **IM/咨询**：接入第三方 SaaS（环信/融云等）以降低自研成本，支持文本+语音留言。
- **支付**：微信支付 H5（纯支付，不含分账/自动退款），人工对账。
- **安全与合规**：https、实名认证、执业证书上传、日志留存、敏感信息脱敏。

## 6. 成本估算
### 完整方案（参考）
- 首页/导航：8k-12k
- 律师列表+详情：10k-15k
- 下单+支付：15k-20k
- 在线咨询 IM：18k-25k（自研）
- 文书定制：12k-18k
- 订单中心：10k-15k
- 消息中心：8k-10k
- 用户中心：10k-14k
- 管理后台：20k-30k
- **整包**：≈35w-55w（含需求、设计、开发、测试、上线、3 个月支持）

### 精简方案（成本优化）
| 模块 | 精简策略 | 费用（RMB） |
| --- | --- | --- |
| 原型/UE | 使用政务模板、低保真 | 4k-6k |
| 前端实现 | 仅用户端 H5，模块化复用 | 18k-22k |
| 后端服务 | NestJS + MySQL，核心业务接口 | 16k-20k |
| 第三方 IM | SaaS 对接、配置 | 4k-6k |
| 文书定制 | 结合低代码表单/模板 | 5k-7k |
| 测试与上线 | 冒烟测试、公众号发布 | 3k-4k |
| **总计** |  | **50k-65k** |

> 通过第三方 IM、低代码文书流程、简化后台，成本较完整自研方案下降 70% 以上。

## 7. 风险与建议
- 律师资料需合规验证，提前准备执业证书、实名认证流程。
- 支付、合同签署涉及微信及电子签服务资质，需预留审批时间。
- 第三方 IM、表单若不满足后续需求，可留接口后期替换自研方案。
- 数据安全（日志、脱敏、存储）需在 MVP 阶段即规划，避免后期整改成本。
