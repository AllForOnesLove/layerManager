# 使用GitHub Actions自动打包Windows EXE

## 🎯 快速开始

### 1. 创建GitHub仓库并上传代码

```bash
cd ExcelMergerTool
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/ExcelMergerTool.git
git branch -M main
git push -u origin main
```

### 2. 触发打包

1. 打开GitHub仓库
2. 点击 "Actions" 标签
3. 选择 "Build Windows EXE"
4. 点击 "Run workflow"

### 3. 下载exe文件

打包完成后，在Actions页面下载Artifacts中的exe文件。
